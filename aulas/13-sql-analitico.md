# Aula 13 — SQL analítico

[← Aula 12](./12-estatistica-aplicada.md) · [Índice](../README.md#cockpit-das-40-aulas) · [Aula 14 →](./14-revisao-dos-fundamentos.md)

## Objetivo

Consultar dados com filtros, agregações, joins, subconsultas e funções de janela mantendo o grão explícito.

## Estude nesta ordem

1. [Tutorial SQL do PostgreSQL](https://www.postgresql.org/docs/current/tutorial-sql.html)
2. [Consultando uma tabela](https://www.postgresql.org/docs/current/tutorial-select.html)
3. [Joins](https://www.postgresql.org/docs/current/tutorial-join.html)
4. [Funções de janela](https://www.postgresql.org/docs/current/tutorial-window.html)

## Prática e entrega

Carregue o dataset analisado em um banco e responda cinco perguntas, incluindo join, agregação, CTE e janela. Valide resultados no Python.

## Avance quando

- [ ] Cada consulta declara o grão do resultado.
- [ ] Resultados críticos foram reconciliados por outro cálculo.
