[← Aula 05](./05-arquivos-erros-e-validacao.md) · [Índice](../README.md#cockpit-das-40-aulas) · [Aula 07 →](./07-projeto-python.md)

## Objetivo

Representar uma entidade com classe quando isso simplificar as regras e consumir uma API HTTP com segurança.

## Estude nesta ordem

1. [Classes em Python](https://docs.python.org/pt-br/3/tutorial/classes.html)
2. [urllib.request](https://docs.python.org/pt-br/3/library/urllib.request.html)
3. [JSON na biblioteca padrão](https://docs.python.org/pt-br/3/library/json.html)

## Prática e entrega

Integre uma API pública ao projeto. Defina timeout, valide a resposta e trate indisponibilidade sem perder os dados locais.

## Avance quando

- [ ] Você explica por que usou — ou não usou — uma classe.
- [ ] A integração trata timeout, erro HTTP e formato inesperado.
